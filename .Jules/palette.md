## 2024-02-28 - Missing Focus States on Tailwind Icon Buttons
**Learning:** In Tailwind CSS, icon-only buttons (like hamburger menus or search toggles) often miss explicit focus states (`focus-visible:ring-*`), making keyboard navigation invisible. This pattern frequently occurs in custom WordPress themes using Tailwind where standard form elements are customized.
**Action:** Always verify keyboard accessibility on custom interactive elements (buttons, toggles, close buttons). Apply `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-primary focus-visible:ring-offset-2` to ensure consistent, highly visible focus indicators across the app.
