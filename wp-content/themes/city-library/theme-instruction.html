1. С чего начать

Для управления сайтом вам необходимо войти в панель администратора WordPress (обычно по адресу ваш-сайт.ru/wp-admin). После входа вы увидите черную панель слева — это ваше главное меню управления.

Основные разделы, которые вам понадобятся:

  • Записи: Для публикации новостей, анонсов и событий.
  • Страницы: Для постоянной информации ("О нас", "Правила", "История").
  • Внешний вид -> Настроить: Самый важный раздел для настройки дизайна.
  • Внешний вид -> Меню: Для управления ссылками в шапке сайта.

2. Управление контентом

Создание новости (Записи)

  1. Перейдите в Записи -> Добавить новую.
  2. Заголовок: Введите название новости (например, "Библионочь 2024: Как это было"). Старайтесь уложиться в 70 символов.
  3. Текст: Используйте редактор блоков. Чтобы добавить текст, просто начните печатать. Чтобы добавить картинку внутри текста, нажмите "плюсик" (+) и выберите "Изображение".
  4. Изображение записи (Featured Image): В правой колонке настроек найдите вкладку "Запись", прокрутите вниз до блока "Изображение записи" и загрузите главную картинку.
    Это обязательно! Эта картинка будет отображаться на главной странице в сетке новостей.
  5. Отрывок (Excerpt): В правой колонке найдите поле "Отрывок". Напишите 1-2 предложения (анонс). Этот текст выводится под картинкой на главной странице.
  6. Рубрики: Отметьте галочкой нужную рубрику (Новости, Афиша и т.д.).
  7. Нажмите Опубликовать.

Создание страницы

  1. Перейдите в Страницы -> Добавить новую.
  2. Процесс аналогичен записям, но страницы не имеют рубрик и меток.
  3. Страницы используются для статичной информации. После создания страницу нужно добавить в Меню (см. раздел 6).

3. Справочник по изображениям

Важно: Соблюдение размеров изображений — гарантия того, что сайт будет выглядеть профессионально. Загружайте изображения в формате JPG (для фото) или PNG (для логотипов с прозрачностью).
Блок / Элемент Рекомендуемый размер Пояснение
Первый экран (Hero) 1920 x 1080 px Большое фоновое изображение. Тема автоматически накладывает затемнение для читаемости текста.
Карточка новости 800 x 600 px (4:3) Или 1200x900. Главное — придерживаться горизонтального формата и одинаковых пропорций для всех новостей.
Слайдер "Афиша" 800 x 1000 px Вертикальный формат (портретный) лучше всего смотрится на мобильных устройствах.
Промо-блок 600 x 400 px Картинка приветствия справа от текста.
Логотипы партнеров Высота 150-200 px Формат PNG с прозрачным фоном. Ширина любая.
Иконки "Важное" 500 x 500 px Квадратные картинки. Желательно логотипы или простые иконки.
Модальное окно Любой (адаптируется) Изображение автоматически подстраивается по высоте экрана (max 50% высоты), чтобы не перекрывать кнопку закрытия.

4. Визуальная настройка (Customizer)

Все настройки внешнего вида находятся в разделе: Внешний вид -> Настроить.

Глобальные настройки

  • Свойства сайта: Загрузите логотип библиотеки и измените название сайта.
  • Глобальные цвета: Выберите "Основной цвет" (например, ваш фирменный зеленый или синий). Кнопки, ссылки и акценты на всем сайте автоматически изменятся.
  • Настройки кнопок: Задайте форму (круглые, квадратные) и цвета для всех кнопок на сайте.
  • Типографика: Выберите шрифты для заголовков (например, строгий Inter или классический Merriweather) и основного текста.

5. Настройка блоков главной страницы

Главная страница состоит из блоков, которые можно включать, выключать и настраивать.

Блок "Hero" (Первый экран)

  • Фон: Загрузите изображение.
  • Текст: Измените заголовок ("Твой мир, Твоя библиотека") и подзаголовок.
  • Кнопки: Вы можете добавить до 2-х кнопок ("Афиша", "Узнать больше").
    Лайфхак: Если удалить текст кнопки в настройках, кнопка исчезнет с сайта.
  • Выравнивание: Текст можно сдвинуть влево, вправо или оставить по центру.
  • Версия для слабовидящих: Кнопка "Глаз" автоматически появляется в правом верхнем углу этого блока.

Блок "Афиша мероприятий"

  • Это слайдер (листалка) для анонсов.
  • Вы можете загрузить до 5 слайдов. Для каждого слайда задается картинка, заголовок, дата и ссылка.
  • Можно добавить ярлычки, например "NEW" или "Скоро".

Блок "Важная информация"

  • Блок с круглыми или квадратными иконками-ссылками (например, "Госуслуги", "НЭБ").
  • Загрузите до 8 картинок и укажите ссылки для них.
  • В настройках можно менять стиль иконок (тень, черно-белый эффект).

Блок "Наши партнеры"

  • Загрузите логотипы партнерских организаций.
  • Размер логотипов: Используйте новую настройку "Размер логотипов", чтобы выбрать идеальный масштаб (от XS до 3XL).

Блок "Новости"

  • Выводит последние 8 новостей автоматически.
  • В настройках "Стили карточек новостей" можно изменить цвета заголовков и фона карточек.

6. Меню и Навигация

Настройка верхнего меню

  1. Перейдите в Внешний вид -> Меню.
  2. Выберите меню для редактирования или создайте новое.
  3. Добавьте страницы из списка слева.
  4. Чтобы создать выпадающее меню (подпункты), просто перетащите пункт чуть правее под "родительский" пункт.
  5. Внизу поставьте галочку "Primary Menu" (Основное меню) и сохраните.

Мобильное меню

На мобильных устройствах меню сворачивается в кнопку "Меню". Дизайн мобильного меню ("шторка") настраивается в разделе "Нижнее мобильное меню" в Customizer. Вы можете выбрать один из 10 стилей (например, "iOS Blur" или "Neon").

7. Подвал (Footer)

В настройках футера можно:

  • Контакты: Указать телефон, Email и Адрес. Они появятся автоматически.
  • Соцсети: Вставьте ссылки на вашу группу ВКонтакте, Telegram, Одноклассники или YouTube. Иконки появятся сами.
  • Карта: Включить Яндекс.Карту (потребуются координаты).
  • Стиль: Выберите "Centered" (По центру) для чистого дизайна с белым фоном, или "Default" для темного подвала.

8. Версия для слабовидящих

Всё включено: Тема соответствует стандарту доступности (ГОСТ).

В правом верхнем углу сайта всегда доступна кнопка "Версия для слабовидящих". Она переключает три режима:

  1. Обычный: Стандартный дизайн.
  2. Крупный шрифт: Увеличение текста на 30%.
  3. Высокая контрастность (AAA): Черный фон, белый текст, желтые ссылки. Все декоративные элементы скрываются для максимальной читаемости.

Выбор пользователя запоминается и сохраняется при переходе между страницами.

9. Частые вопросы

Вопрос: Я загрузил картинку, а она обрезалась.
Ответ: Проверьте размеры. Скорее всего, картинка была слишком маленькой или квадратной там, где нужна прямоугольная. См. раздел 3.
Вопрос: Кнопка в блоке "Hero" не исчезает, хотя я удалил ссылку.
Ответ: Нужно удалить текст кнопки в настройках, а не только ссылку.
Вопрос: Модальное окно (всплывающее объявление) не появляется.
Ответ: Оно показывается одному посетителю только один раз за сессию (чтобы не надоедать). Попробуйте открыть сайт в режиме "Инкогнито", чтобы увидеть его снова. Также проверьте настройку "Задержка" — если стоит 0, оно появится сразу при загрузке.
