# Virtual Librarian Plugin

AI-powered Chatbot and Voice Assistant for WordPress.

## Features
- AI Chat integration via OpenRouter.
- Voice Control using Web Speech API.
- Automated Knowledge Base synchronization.
- Customizable themes (VK, Telegram, WhatsApp, macOS).
- Shortcode `[virtual_librarian]` for embedding.
- Theme-independent functionality.

## Installation
1. Upload the `virtual-librarian` folder to `/wp-content/plugins/`.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Configure settings under **Settings -> Virtual Librarian**.

## Settings
- **API Key**: Required OpenRouter API key.
- **Models**: Choose primary and fallback LLM models.
- **Voice**: Configure pitch and rate for the assistant.

## Requirements
- WordPress 6.0+
- PHP 8.0+
