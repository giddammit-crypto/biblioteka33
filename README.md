# City Library Theme (МБУК ЦГБ г. Владимира)

Современная, быстрая и доступная WordPress тема для Центральной городской библиотеки.
Оснащена передовыми инструментами доступности (версия для слабовидящих), встроенным Виртуальным библиотекарем на базе ИИ и голосовым ассистентом.

## Виртуальный библиотекарь (Чат-бот на базе ИИ)

В теме реализован продвинутый ИИ-помощник, использующий API OpenRouter.

### Основной функционал:
*   **Генерация текстов и сценариев:** Написание постов, планов мероприятий, подбор литературы (с полным исключением иностранных агентов).
*   **Генерация изображений:** Команда `/aimg [описание]` или фраза "Нарисуй..." создает изображения (DALL-E 3, Flux, Stable Diffusion). Если нейросети перегружены, генерируется картинка через резервный Markdown-алгоритм Pollinations.
*   **Сбор черновиков (Авторы/Юбиляры):** По запросу `/author [Имя]` или при нажатии на кнопку "Собрать черновик" ИИ генерирует статью и автоматически сохраняет её как черновик записи (Post Draft) в админ-панели WordPress.
*   **Быстрые действия:** Кнопки `/юбиляры`, `/emoji`, `/stat` для мгновенных ответов.
*   **Экспорт ответов:** Возможность скачать ответ ИИ в форматах `.txt`, `.docx` (с полной поддержкой кириллицы) или `.pdf` (через форму печати), а также отправить ответ на указанный Email.
*   **Память и контекст:** Библиотекарь знает всех авторизованных пользователей по имени, имеет доступ ко всем страницам сайта и новостям, и строго ограничен реальной базой филиалов библиотеки.
*   **Прикрепление файлов:** Загрузка документов (.txt, .docx, .pdf) и изображений (.jpg, .png, .webp) до 50МБ. ИИ извлекает текст и визуальные данные из файлов.
*   **Зрительный анализ PDF (Vision):** Библиотекарь теперь умеет "видеть" страницы PDF. Даже если файл состоит только из картинок, ИИ проведет OCR, определит цветовую схему, шрифты и стиль оформления.
*   **Режим инструкций (Brandbook):** Загруженные PDF-файлы служат приоритетными инструкциями. Библиотекарь будет создавать афиши и посты, строго соблюдая правила из вашего брендбука до конца сессии.
*   **Темы оформления:** 5 визуальных стилей чата (Библиотека, ВКонтакте, Telegram, WhatsApp, macOS), переключаемых в Настройках темы.
*   **Аватары:** 5 векторных аватаров (женщина, мужчина, сова, робот, абстракция) на выбор, либо загрузка собственного изображения.

### Голосовой Ассистент
ИИ-библиотекарь также может общаться голосом. Он умеет распознавать речь (через Web Speech API / Whisper) и отвечать вслух (TTS), ограничивая свои аудио-ответы первыми 3 предложениями для лаконичности. Навигация по сайту и поиск по каталогу (OPAC) также поддерживают голосовые команды.

## Журнал изменений (Changelog)

**[Версия 1.4.0]**
- **Зрительный Анализ PDF:** ИИ теперь анализирует PDF как визуальный объект. Поддерживается извлечение стилей, цветов и текста из PDF-сканов (без текстового слоя).
- **Мультимодальность:** Внедрена поддержка Gemini 2.0 Flash для одновременной обработки текста и нескольких изображений со страниц документов.

**[Версия 1.3.0]**
- **Поддержка PDF (до 50МБ):** Внедрена глубокая поддержка PDF-файлов. Текст извлекается на стороне клиента (PDF.js) и передается ИИ.
- **Контекстная Память:** ИИ теперь умеет запоминать инструкции из загруженных файлов (например, правила брендбука) и использовать их во всех последующих ответах и генерациях изображений до очистки диалога.
- **Шрифтовое Единство:** Шрифт **Montserrat** установлен как основной по умолчанию для всей темы (заголовки, текст, меню).

**[Версия 1.2.0]**
- **Умные Код-блоки:** Добавлена кнопка "Копировать" для всех блоков кода в чате с ИИ.
- **Мульти-форматный Экспорт:** Полноценная поддержка генерации и скачивания DOCX и PDF файлов из выбранных сообщений чата (функция "Собрать черновик").
- **Безопасность Иноагентов:** Внедрена система автоматического детектирования и визуального предупреждения (бейдж "Иноагент") при упоминании лиц из реестра иностранных агентов.
- **Интеграция с Редактором:** В админ-панель WordPress (Gutenberg) добавлены инструменты ИИ для улучшения текста и быстрой вставки эмодзи.
- **Визуальное Совершенство:** Улучшены анимации бейджей, добавлен плавный скролл к последнему сообщению и кнопка быстрого возврата вниз.
- **Книжные Обложки:** Автоматический поиск и отображение обложек книг через Google Books API прямо в окне чата.

**[Версия 1.1.0]**
- **Универсальный Lightbox:** Теперь абсолютно все изображения в статьях, новостях, галереях, промо-блоках и карточках открываются в модальном окне GLightbox.
- **Улучшение футера:** Добавлены переключатели в Customizer для отображения/скрытия ссылок на "Политику конфиденциальности" и "Карту сайта".
- **Исправление генерации изображений:** Полностью переписан модуль генерации картинок (/aimg). Внедрена поддержка современных моделей Flux (Schnell/Dev) через OpenRouter с обработкой нативных мультимодальных ответов.
- **Интеллектуальный Библиотекарь:** Улучшена личность ИИ (Вероника), добавлена поддержка анализа прикрепленных файлов (.txt, .docx) для реальной работы с документами.
- **Исправления Firefox:** Устранены ошибки отображения текста в карточках новостей в браузере Firefox.
- **Форматирование:** Стандартизировано отображение Gutenberg-блоков (выравнивание, таблицы, цитаты) для профессионального вида страниц.
- **Безопасность:** Все AJAX-запросы защищены nonces, а системный промпт ИИ исключает галлюцинации и упоминание иноагентов.
