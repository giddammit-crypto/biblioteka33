# City Library Ecosystem (МБУК ЦГБ г. Владимира)

Профессиональная экосистема для библиотек, состоящая из современной WordPress темы и мощного плагина Виртуального библиотекаря на базе ИИ.

## 🏛️ Тема City Library
Современная, быстрая и доступная тема, оптимизированная для редакционного контента и соответствия стандартам доступности.

### Особенности темы:
- **Типографика и дизайн:** Основной шрифт Montserrat, высота строки 1.85 и продуманные отступы для комфортного чтения.
- **Стабильность:** Специальные CSS-исправления для корректного рендеринга в Firefox (изолированные контексты наложения).
- **Доступность:** Встроенная панель настроек для слабовидящих (ГОСТ Р 52872-2019 AA) с поддержкой тем контрастности и масштабирования.
- **Интерактивность:** Полная интеграция с GLightbox для всех изображений, адаптивные слайдеры Swiper и интеграция с Яндекс.Картами.
- **Производительность:** Оптимизированные циклы WordPress и минимизация N+1 запросов к базе данных.

## 🤖 Плагин Virtual Librarian
Интеллектуальное ядро системы, вынесенное в отдельный плагин для максимальной гибкости и стабильности.

### Функциональные возможности:
- **Мультимодальный ИИ:** Работает на базе моделей Gemini 2.0 Flash и GPT-4o через OpenRouter. Анализирует текст, изображения и документы.
- **Анализ файлов:** Поддержка загрузки и обработки PDF (с визуальным анализом страниц) и DOCX (с извлечением текста).
- **База знаний и Поиск:** Автоматическая ежедневная синхронизация с сайтом biblioteka33.ru. ИИ выполняет поиск по локальной базе данных сайта для предоставления точных ответов.
- **Голосовой ассистент:** Полноценное управление голосом для мобильных устройств и киосков. Синтез речи ограничен 3 предложениями для краткости.
- **Профессиональная Админка:** Стильный интерфейс настроек с табами, статистикой и ручным управлением синхронизацией.
- **Сборка документов:** Функция коллективного выбора ответов ИИ для формирования и скачивания готовых черновиков или документов.

## Установка и настройка
1. Активируйте тему **City Library**.
2. Активируйте плагин **Virtual Librarian**.
3. Перейдите в раздел `Настройки -> ИИ Библиотекарь` для ввода API ключа OpenRouter.
4. Вкладка `Система` позволяет вручную запустить синхронизацию базы знаний филиалов.
