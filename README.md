# City Library Theme (МБУК ЦГБ г. Владимира)

Современная, быстрая и доступная WordPress тема для Центральной городской библиотеки.
Оснащена передовыми инструментами доступности (версия для слабовидящих), встроенным Виртуальным библиотекарем на базе ИИ и голосовым ассистентом.

## Виртуальный библиотекарь (Чат-бот на базе ИИ)

В теме реализован продвинутый ИИ-помощник, использующий API OpenRouter.

### Основной функционал:
*   **Генерация текстов и сценариев:** Написание постов, планов мероприятий, подбор литературы (с полным исключением иностранных агентов).
*   **Генерация изображений:** Команда `/aimg [описание]` или фраза "Нарисуй..." создает изображения (DALL-E 3, Flux, Stable Diffusion). Если нейросети перегружены, генерируется картинка через резервный Markdown-алгоритм Pollinations.
*   **Сбор черновиков (Авторы/Юбиляры):** По запросу `/author [Имя]` или при нажатии на кнопку "Собрать черновик" ИИ генерирует статью и автоматически сохраняет её как черновик записи (Post Draft) в админ-панели WordPress.
*   **Быстрые действия:** Кнопки `/юбиляры`, `/emoji`, `/stat` для мгновенных ответов.
*   **Экспорт ответов:** Возможность скачать ответ ИИ в форматах `.txt`, `.docx` (с полной поддержкой кириллицы) или `.pdf` (через форму печати), а также отправить ответ на указанный Email.
*   **Память и контекст:** Библиотекарь знает всех авторизованных пользователей по имени, имеет доступ ко всем страницам сайта и новостям, и строго ограничен реальной базой филиалов библиотеки.
*   **Прикрепление файлов:** Интегрированная кнопка "Скрепка" для загрузки файлов до 20МБ (на данный момент имитация интерфейса; парсинг в разработке).
*   **Темы оформления:** 5 визуальных стилей чата (Библиотека, ВКонтакте, Telegram, WhatsApp, macOS), переключаемых в Настройках темы.
*   **Аватары:** 5 векторных аватаров (женщина, мужчина, сова, робот, абстракция) на выбор, либо загрузка собственного изображения.

### Голосовой Ассистент
ИИ-библиотекарь также может общаться голосом. Он умеет распознавать речь (через Web Speech API / Whisper) и отвечать вслух (TTS), ограничивая свои аудио-ответы первыми 3 предложениями для лаконичности. Навигация по сайту и поиск по каталогу (OPAC) также поддерживают голосовые команды.
